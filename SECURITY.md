# OpenCADC Security Policy

We take the security of our software and systems seriously. Thank you for helping keep our
organization and users safe through responsible disclosure.

## Supported Versions

Unless otherwise noted in a specific repository, we provide security updates for the
**latest major release** and the **`main` (or default) branch** of actively maintained 
repositories.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report them privately using one of the following methods:

1. **GitHub Private Vulnerability Reporting (Preferred):** Navigate to the **Security** tab
of the affected repository and click **"Report a vulnerability"** to open a confidential
security advisory.
2. **Email:** If private reporting is not enabled on a repository or you cannot use GitHub, 
send an email to **[security@canfar.net](mailto:security@canfar.net)**.

### What to Include
To help us triage and resolve the issue quickly, please include:
* The affected repository name, version, or commit hash
* A clear description of the vulnerability and its potential impact
* Step-by-step instructions or a proof-of-concept to reproduce the issue
* Any suggested fixes or mitigations, if known

## What to Expect

* **Acknowledgment:** We will acknowledge receipt of your report as soon as possible (within **3 business days**??).
* **Updates:** We will keep you informed as we investigate, validate, and work on a fix.
* **Disclosure:** Please allow us reasonable time to investigate and release a patch before disclosing the
vulnerability publicly. Once resolved, we will coordinate disclosure and credit your contribution if you wish.

## Safe Harbor

We consider security research conducted in good faith—without accessing, modifying, or destroying user data, 
and without disrupting our services—to be authorized and welcome.
